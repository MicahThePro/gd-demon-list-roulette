# GD List Roulette Feature Roadmap

This document is a big backlog of feature ideas ranked by impact and effort. It is designed to serve as a product wishlist, sprint planning document, and future roadmap for GD List Roulette.

Legend:
- 1 Star = very quick and easy
- 3 Stars = small but worthwhile
- 5 Stars = meaningful feature
- 7 Stars = large feature with real product value
- 10 Stars = highly ambitious, big-scope, game-changing feature

Priority is roughly based on a mix of:
- effort required
- user value
- gameplay impact
- community appeal
- technical complexity

---

## 1 Star Features (Easy wins)

### 1.1 Add a tiny "How to Play" popover
- Easy explanation of the roulette flow
- Short tutorial on starting a run, clearing levels, and failed attempts
- Helps brand-new players immediately understand the game

### 1.2 Add a small "copy run summary" button
- Copy the current run state to clipboard
- Useful for sharing run progress with friends

### 1.3 Add keyboard shortcuts
- Press Enter to submit
- Press Escape to close menus
- Improves speed and accessibility

### 1.4 Show a "last run" summary card
- Display the previous run outcome at a glance
- Great for replayability

### 1.5 Add a daily challenge mode
- One random challenge seed per day
- Gives players a repeatable daily goal

### 1.6 Add a "Reset current run" button
- Removes current progress instantly
- Useful for players who made a mistake

### 1.7 Add a floating status message for approvals/submissions
- Better feedback when a run is accepted or rejected
- More polished than silent failure states

### 1.8 Add support for compact mobile mode
- Lighter layout for smaller screens
- More usable on phones and tablets

### 1.9 Add better empty-state text for lists
- If a list is empty or data fails to load, show clearer messaging
- Reduces confusion

### 1.10 Add a visible current list label on the screen
- Show exactly which list is active at a glance
- Helpful when switching between challenge sources

### 1.11 Add a "retry loading list" button
- If challenge data fails, let the user reload it without refreshing the page

### 1.12 Add a small badge for version number
- Show the current app version in UI
- Helps track release differences

### 1.13 Add a filter to hide completed runs in history
- Cleaner history view
- Keeps leaderboard and personal run history easier to scan

### 1.14 Add a line for current target percent
- More explicit than only showing current percentage when a run is in progress

### 1.15 Add more obvious success/fail color states
- Green for clear, red for fail, neutral for other states
- Helps players read the screen at a glance

### 1.16 Add a "small latency warning" when server is slow
- Better UX when backend or network is delayed

### 1.17 Add a run history count badge
- Example: “12 runs this week”
- Feels rewarding and gives progress feedback

### 1.18 Add a better user-friendly account status banner
- Show if a user is signed in, guest, or limited mode

### 1.19 Add list source sorting options
- Sort by name or difficulty
- Helpful when many sources are available

### 1.20 Add a version changelog entry indicator
- Show a dot or badge when there is a new changelog item

## Suggested Roadmap Order

If you want to build this in a practical way, here is a sensible order:

### Phase 1: Quick wins (1–3 stars)
- tutorials
- better messaging
- local run persistence
- run history improvements
- achievements basics

### Phase 2: Engagement upgrades (4–5 stars)
- profiles
- stats dashboards
- better filtering
- weekly/monthly events
- community challenge packs

### Phase 3: Social/community expansion (6–7 stars)
- social feed
- following
- clubs
- ranking seasons
- featured challenge packs

### Phase 4: Major platform growth (8–10 stars)
- creator economy
- full challenge ecosystem
- advanced analytics
- world-class event system
- broad community platform ideas

## Best “starter” features to ship first

If the goal is to improve the app quickly without overbuilding too soon, these are the best first moves:

1. Better onboarding/tutorial
2. Local run saving and resume
3. Run stats and personal history
4. Challenge source filters and presets
5. Achievements
6. Better moderation tooling
7. Weekly event rotation
8. Profile page
9. Community event board
10. Creator/curator tools

These give the app immediate value while keeping the scope realistic and fun.

## Final note

The biggest value in GD List Roulette is not just random levels — it is the mix of:
- community identity
- leaderboard pressure
- challenge curation
- repeatable progression
- social competition
- fresh seasonal events

If you build enough of the smaller and medium features well, the app will naturally evolve into something much bigger than a simple roulette tool.
